# selfdrive 2.0.0

让一台机器自己给自己派活、自己验收的程序。**不训练模型、不改自己的大脑**——
它只能改两样东西：记忆（台账、日志）和手上的工具（脚本）。

一圈的流程：

```
采集外部信号 ──→ 算偏差/痛值 ──→ 从八个候选池里挑一件事 ──→ 交给"干活的那个"去执行
      ↑                                                          │
      └──────── 机械判官打分(0-10) ←── 台账记账 ←── 验收卡 ←──────┘
```

判官是脚本，不是模型：先看能不能跑、产物在不在、指标过没过，再给分。
分进台账，下一轮挑活时按池子的实测均分做**收缩加权**（`(avg*w + 4*12)/(w+12)`，
样本少就往中位分靠），所以它不会因为某一池偶然刷出高分就一直干那一池。

## 目录

| 路径 | 说明 |
|---|---|
| `core/` | 引擎与各池料源，纯标准库，无第三方依赖 |
| `local/` | **私货位**：你自己的余额、身体/机器信号、课程表、片单、目标都放这儿，格式见 `local/README.md` |
| `docs/` | 架构与池子说明 |

## 起手

```bash
export SELFDRIVE_HOME=/path/to/your/data     # 运行数据放这儿；不设就放在 core 旁边
python core/iter_cycle.py --show             # 只读：看这一圈会挑什么
python core/iter_cycle.py                    # 只算不写
python core/iter_cycle.py --commit            # 落盘：decision + log
```

`local/` 里一个文件都没有也能跑：缺哪个就降级哪一块，缺余额就当没钱、缺课程表就跳过学习池。

## 边界（重要）

这东西的价值在"账本可查"，不在"它很聪明"。设计上刻意：

- 判官机械、可复现，同一产物打分同一结果；
- 每轮有成本上限，且必须先查余额（`docs/ARCHITECTURE.md` 的闸门一节）；
- 高危动作（动钱、删数据、对外发言）不在自动范围内，只出方案。
